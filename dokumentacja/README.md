## Szybki start
Zacznij od [podstaw HTML](01-html-css/podstawy-html.md). Dalej możesz przejść do [PHP](06-php/podstawy-php.md) lub [C++](03-cpp/podstawy-cpp.md), zależnie od tego, jaki backend chcesz poznać.

## Wymagane narzędzia
- **Edytor kodu**: VS Code (darmowy)
- **Przeglądarka**: Chrome/Firefox
- **Kompilator C++**: MinGW lub Visual Studio
- **PHP**: PHP CLI lub XAMPP
- **Serwer lokalny**: wbudowany serwer PHP, XAMPP lub Python (do testowania)
